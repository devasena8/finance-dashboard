# 💰 Personal Finance Dashboard

A responsive personal finance dashboard built with React that helps users track their income and expenses, organize transactions by category, and visualize their financial activity through charts.

## 🚀 Features

- 💵 Track income
- 💸 Track expenses
- 🏷️ Categorize transactions
- 📊 Visualize financial data with charts
- 💰 Calculate total income
- 💸 Calculate total expenses
- 🧮 Calculate current balance
- 📋 View transaction history
- 🗑️ Delete transactions
- 💾 Store transactions using browser localStorage
- 📱 Responsive dashboard UI

## 🛠️ Tech Stack

- **React** – Frontend library
- **JavaScript** – Application logic
- **Vite** – Development and build tool
- **Recharts** – Data visualization
- **CSS** – Styling
- **LocalStorage** – Client-side data persistence
